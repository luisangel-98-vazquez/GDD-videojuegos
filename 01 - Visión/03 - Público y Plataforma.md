# Público y Plataforma

## Descripción de la sección

Define para quién se diseña el videojuego y dónde se jugará. Las decisiones de diseño, interfaz, controles y rendimiento dependen de estas variables.

Jóvenes y adultos que disfrutan los juegos de rol, la acción y aventura, la exploración de mundos oscuros y las historias sobrenaturales. También puede interesar a jugadores que quieran conocer una interpretación fantástica de elementos de la mitología mexica.

## Público objetivo

**Edad aproximada:** 15 a 30 años.

**Experiencia esperada:**  
> Casual, ==🟡intermedia==, avanzada.

**Intereses relevantes:** Videojuegos RPG, exploración, mitología, fantasía, combate y narrativa.

**Conocimientos previos necesarios:** No se requieren conocimientos previos; el juego incluirá instrucciones para aprender las mecánicas y los controles.

## Plataforma

| Elemento                | Decisión                  |
| ----------------------- | ------------------------- |
| Plataforma principal    | PC (Windows)              |
| Plataformas secundarias | Web                       |
| Método de entrada       | Teclado / Mouse / Control |
| Resolución objetivo     | 1920 × 1080 píxeles       |
| Relación de aspecto     | 16:9                      |
| Rendimiento objetivo    | 60 FPS                    |
| Conexión requerida      | No                        |
|                         |                           |

## Restricciones de plataforma

Documenta limitaciones de hardware, controles, memoria, almacenamiento, distribución o conectividad.

El juego estará enfocado principalmente en PC con Windows. Se buscará que funcione en equipos de gama media sin requerir hardware especializado. Al ser un juego 2D con arte dibujado a mano (_hand-drawn_), se priorizará el rendimiento estable y la fluidez de las animaciones.

## Sesión de juego

**Duración esperada de una sesión:** 5 min

**Duración total estimada del juego:** 20 min 

## Modelo de distribución

> Gratuito, pago único, educativo, ==🟡prototipo académico==, etc.
