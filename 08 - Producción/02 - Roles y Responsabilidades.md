## Responsabilidad

Cada entregable importante debe tener una persona responsable de coordinarlo, aunque varias personas participen en su elaboración.

| Entregable | Responsable |
| ---------- | ----------- |
| GDD actualizado | Esther |
| Proyecto de Unity y compilaciones | Josué |
| Prototipo y sistema de combate | Luis |
| MVP | Joel |
| Vertical slice | Joel, con Ramón y Kevin en los recursos finales |
| Nueve regiones ensambladas | Joel |
| Arte final | Ramón |
| Animación y audio finales | Kevin |
| Guion, recuerdos y epílogo | Esther |
| Informe de pruebas | Esther |

Quien programa o crea un elemento no es quien lo aprueba: cada fusión la revisa otra persona, y QA prueba cada hito.
