# Jugabilidad

## Descripción de la sección

La jugabilidad explica **qué hace el jugador, qué recibe a cambio y cómo evoluciona la experiencia**.

## Bucle principal de juego

Describe el ciclo que se repite durante la experiencia.

**Ejemplo conceptual:**

`Explorar → Encontrar desafío → Resolver → Obtener recompensa → Mejorar → Explorar`

**Bucle del proyecto:**
inicia -> explora -> se topa con enemigo -> combate -> obtiene puntos de niveles -> explora 

## Acciones principales del jugador

| Acción   | Propósito                                                        | Resultado                                              |
| -------- | ---------------------------------------------------------------- | ------------------------------------------------------ |
| combate  | atacar a los enemigos para abrirse paso                          | obtiene puntos de experiencia al derrotar enemigos     |
| explorar | que el jugador tenga curiosidad de ver detalles dentro del nivel | obtiene herramientas, nivel o un fragmento de narrtiva |
|          |                                                                  |                                                        |

## Experiencia segundo a segundo

¿Qué hace el jugador durante los primeros minutos?
se le empezara adentrar en la narrativa y las mecanicas basicas de movimiento y combate
## Experiencia minuto a minuto

¿Qué actividades se repiten durante una sesión?
movimiento, combate, exploracion
## Experiencia a largo plazo

¿Qué hace que el jugador quiera continuar?
la intriga por la narrativa
conocer el mictlan
## Condición de victoria

¿Qué debe lograr el jugador para avanzar o terminar?
para avanzar se le pondra obstaculos para el siguiente nivel, existiran casos con que solo llegue a la meta del nivel.
narrativamente para ganar debe llegar al nivel final y derrotar al jefe
## Condición de derrota

¿Qué situaciones provocan fracaso?
ser derrotado por enemigos y jefes

## Ritmo

Describe cómo alternan:

- Exploración
- Acción
- Descanso
- Desafío
- Recompensa
- Historia

el jugador explora el nivel y recolecta herramientas y objectos que ofrecen puntos de niveles o dejan mas peso en la narrativa de un rescate, en lo que explora se encuentra enemigos con los cuales combate por puntos de niveles al final del nivel se puede presentar un reto, una horda de enemigos o un puzle.
## Principios de interacción

¿Qué reglas debe seguir el juego para que las acciones del jugador sean claras, consistentes y predecibles?

mantenerse explorando.
