# Requisitos Técnicos

## Descripción de la sección

Define las condiciones técnicas necesarias para ejecutar y desarrollar el videojuego.

## Requisitos mínimos

**Sistema operativo:** Windows 10 (64-bit)

**CPU:** Intel Core i3 (4ª generación) / AMD FX-6300 o equivalente

**GPU:** Gráficos integrados Intel HD Graphics 4000 / AMD Radeon R5 o tarjeta dedicada básica compatible con DirectX 11

**RAM:** 4 GB

**Almacenamiento:** 1.5 GB de espacio disponible

**Resolución:** 1280 x 720 (720p HD)

**Conexión:** Sin conexión (Juego 100% Offline para un solo jugador)

## Requisitos recomendados

**Sistema operativo:** Windows 10 / Windows 11 (64-bit)

**CPU:** Intel Core i5 (8ª generación) / AMD Ryzen 3 3200G o superior

**GPU:** NVIDIA GeForce GTX 1050 / AMD Radeon RX 560 o superior

**RAM:** 8 GB

**Almacenamiento:** 2 GB de espacio disponible (preferiblemente en SSD para reducir tiempos de carga)
 
## Objetivos de rendimiento

**FPS objetivo:** 60 FPS estables a resolución 1080p

**Tiempo de carga objetivo:** Menor a 5 segundos al cambiar de escena o nivel

**Memoria máxima:** Consumo máximo de memoria RAM de 1.5 GB a 2 GB en ejecución

## Restricciones

- **Plataforma única:** El videojuego está diseñado exclusivamente para PC (Windows) con teclado/mouse. No cuenta con soporte para consolas, dispositivos móviles ni integración con controles de mando (gamepads) en esta fase.
    
- **Modalidad monojugador:** No soporta funcionalidades multijugador ni funciones en red o servidor.
    
- **Resolución y relación de aspecto:** Optimizado para la relación de aspecto 16:9. Resoluciones ultra-wide (21:9) o relaciones cuadradas pueden presentar barras negras laterales para conservar la escala original de los sprites y tilemaps.
    
- **Alcance de assets y nivel de optimización:** Los niveles y mapas están diseñados para cargarse completos en memoria local, ajustados a los límites de tiempo de desarrollo del cuatrimestre académico.
